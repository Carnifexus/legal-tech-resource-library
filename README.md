# Legal Tech Resource Library

Practical, copy-and-paste checklists for lawyers evaluating their own AI-assisted work. Begin with the task you need to accomplish. Use only authorized sources and test a new tool on fictional material.

1. [Deposition Outline Builder](skills/deposition-outline-builder.md) turns authorized sources into a short, editable examination plan with exhibit cues and source checks.
2. [Evidence and PDF Handling](skills/evidence-and-pdf-handling.md) separates originals from working copies, then provides a final check before an authorized document leaves the firm.
